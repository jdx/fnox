# Touch ID UI preview

Use the standalone preview to design and tweak the Fnox Touch ID approval UI; it uses synthetic metadata and never reads credentials or authorizes operations. Build it using the [preview README](../../crates/fnox-core/native/touch-id/preview/README.md), then open `/tmp/fnox-touch-id-build/fnox-touch-id-preview.app` for simulated approval or launch its executable with `FNOX_PREVIEW_AUTH=system` to see the OS-owned Touch ID prompt. Edit `crates/fnox-core/native/touch-id/theme.mts` for colors or `crates/fnox-core/native/touch-id/src/approval-prompt.mm` for the macOS layout, then rebuild to inspect changes.
