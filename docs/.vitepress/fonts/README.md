# Bundled font

Space Grotesk is bundled for deterministic social image generation without
system fonts or network access during the build. The site also uses this file for display headings through a local `@font-face` rule with `font-display: swap`.

Source: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/spacegrotesk)
